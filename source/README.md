# Splash of Color source archive

Public site content captured from [splashofcolorpainters.com](https://www.splashofcolorpainters.com/) on 2026-09-29.

- `content/`: one Markdown file per sitemap page
- `raw/`: original Wix HTML snapshots
- `assets.json`: local-to-source image manifest
- `color-profile.md`: source Wix theme palette
- `../public/assets/source/`: downloaded original image assets

The redesigned site uses selected assets from this archive while preserving the full source set for reference.
